fastapi
→ Main backend framework.
→ Used to create REST APIs such as:
   GET /prs
   GET /reviewers
   GET /dependencies

uvicorn[standard]
→ ASGI server used to run FastAPI.
→ Starts the backend server.
→ Example:
   uvicorn app.main:app --reload

sqlalchemy
→ ORM (Object Relational Mapper).
→ Used to create database models and interact with PostgreSQL.
→ Example:
   PullRequest
   Reviewer
   Dependency tables

psycopg2-binary
→ PostgreSQL database driver.
→ Connects SQLAlchemy to PostgreSQL.

pydantic
→ Data validation library.
→ Validates API requests and responses.
→ Example:
   PRResponse
   ReviewerResponse

pydantic-settings
→ Loads configuration from environment variables.
→ Used for:
   DATABASE_URL
   GITHUB_TOKEN

python-dotenv
→ Reads .env file automatically.
→ Keeps secrets outside source code.

requests
→ Sends HTTP requests.
→ Used to communicate with GitHub REST API.
→ Example:
   Fetch Pull Requests
   Fetch Reviewers
   Fetch Labels

networkx
→ Graph analysis library.
→ Used to create and analyze PR dependency graphs.
→ Example:
   PR15 → PR20
   PR15 → PR25

apscheduler
→ Background job scheduler.
→ Runs automatic sync jobs.
→ Example:
   Every 10 minutes:
      Fetch GitHub Data
      Update Database
      Recalculate Priorities

python-dateutil
→ Advanced date and time calculations.
→ Used for:
   PR Age Calculation
   Review Time Analysis
   Merge Time Analysis
